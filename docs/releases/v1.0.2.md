# LeanVault 1.0.2

- Save/update prompts dismiss after 10 seconds by default. Change this under
  **Settings → Save to vault options → Dismiss save prompts after (seconds)** (1–300).
- Both dismiss buttons work on the first click. The extension excludes its own
  dialog fields and MFA code fields from credential capture.
- Repeated captures retain one prompt and its original deadline across same-origin
  login/MFA navigation and worker restarts. Identical credentials are suppressed for
  five minutes per tab; changing credentials can trigger a fresh prompt.
- A background alarm syncs every minute, including encrypted data while locked.
  Saving an edit writes to the backend immediately and then refreshes the vault.
  Background refresh preserves unsaved editor fields and does not extend inactivity locking.

## Test this build

1. Reload LeanVault at `chrome://extensions` using the generated `dist/` folder.
   Refresh existing website tabs. Confirm **1.0.2** in extension settings.
2. Submit a new login. Confirm one prompt, first-click dismissal with either **×** or
   **Not now**, and automatic dismissal after 10 seconds. Set the timeout to 30
   seconds and repeat.
3. Submit a login that continues to MFA. Confirm the same prompt keeps its original
   deadline, and dismissing it or entering an MFA code does not produce another.
4. Change a test password in the backend/web vault. With Chrome running, wait for
   the next minute sync and confirm the new password fills. Edit a login in the
   extension and confirm the backend receives it. Keep an unsaved editor draft open
   through a sync and confirm its fields remain unchanged.

Automated validation: TypeScript, Vitest, production build, distribution validation,
and bundle-size checks. The optional real-Chrome page/popup regression checks run with:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs node scripts/check-site.mjs
```

The browser checks use a local test message handler; live account/MFA testing is still
needed for the specific websites and backend in use.
