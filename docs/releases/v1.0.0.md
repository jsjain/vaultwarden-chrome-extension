# LeanVault v1.0.0

LeanVault 1.0.0 is the first public MVP release of the lightweight, independent browser client for
Vaultwarden and compatible Bitwarden API servers.

## Highlights

- Vaultwarden-compatible login, two-step challenges, encrypted sync, unlock, lock, and logout.
- Fast vault search with current-site ranking, favicons, copy, open-site, create, and edit actions.
- Website integration with field-anchored credential suggestions, manual fill, password generation,
  and editable save/update prompts.
- Local password generator with preferences shared between the popup and website fields.
- Browser-session, inactivity, and opt-in encrypted “keep unlocked until logout” modes.
- A compact Manifest V3 interface with dedicated Vault and Generator tabs.

## Security changes

- Fixed credential subdomain oversharing: a login saved for `attacker.targetbank.com` is no longer
  surfaced or authorized for `targetbank.com`.
- Corrected Host, Starts With, Exact, Regular Expression, and Never URI match-mode handling.
- Unknown URI match strategies now fail closed.
- Added regression coverage for the URI authorization boundary.
- Added CodeQL `security-extended` scanning, pull-request dependency review, weekly Dependabot checks,
  and documented GitHub secret scanning.

## Installation

Build and load the tagged source as an unpacked Chrome extension:

```sh
git clone https://github.com/jsjain/vaultwarden-chrome-extension.git
cd vaultwarden-chrome-extension
git checkout v1.0.0
pnpm install
pnpm verify
```

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select `dist/`.
Confirm that LeanVault Settings reports version `1.0.0`.

## Important security notice

LeanVault is unaudited security software. Automated scanners cannot establish that a password
manager is safe. Test with a non-critical account, read [SECURITY.md](../../SECURITY.md), and do not
treat this release as a substitute for an independent cryptography and browser-extension audit.

LeanVault is an independent project and is not associated with, sponsored by, endorsed by, or
