# LeanVault v0.5.1

LeanVault's first public preview release delivers the core Vaultwarden browser-extension workflow
in a compact Manifest V3 package.

## Highlights

- Connect to a custom Vaultwarden-compatible server and sign in with PBKDF2 or Argon2id accounts.
- Sync, decrypt, search, copy, create, and edit personal login items.
- Match logins to the active website and show field-anchored autofill suggestions.
- Fill dynamic login pages, open shadow roots, and same-site login frames more reliably.
- Detect submitted credentials and show an editable save-or-update prompt.
- Generate and fill passwords on new websites using the preferences from the Generator tab.
- Open a saved website directly from its vault row and display local website favicons.
- Configure add/update prompts, excluded domains, and vault lock behavior—including an opt-in
  encrypted "keep unlocked until logout" mode.
- Use the new grey vault icon across Chrome and the extension interface.

## Install

1. Download `leanvault-v0.5.1-chrome.zip` from this release.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
4. Select the extracted folder and confirm LeanVault reports version `0.5.1` in Settings.

## Security notice

This is pre-alpha security software and has not received an independent security audit. Test with
a non-critical account before relying on it for important credentials. Website integration is
optional and requires an explicit Chrome host-permission grant.

## Compatibility notes

The current preview targets standard Bitwarden encryption-v1 accounts. Encryption v2/COSE,
passkeys, organization-owned item editing, attachments, import/export, Duo, and WebAuthn two-step
login are not yet supported.
